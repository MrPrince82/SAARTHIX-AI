# SAARTHIX AI - Frontend Client

Modern React 19 + Vite frontend for SAARTHIX AI, an intelligent career guidance and placement preparation platform.

## Features
- **Placement Readiness Dashboard**: Real-time evaluation of skills, experience, and profile completion.
- **AI Career Mentor**: Powered by Groq AI and Llama/Qwen models for personalized roadmap, interview preparation, and skill advice.
- **Resume Analysis & ATS Scoring**: In-browser PDF extraction using `pdfjs-dist`, keyword matching, section detection, and automated ATS scoring.
- **Skill Gap & Career Roadmap**: Track interactive progress towards your target role (Full Stack, Frontend, Backend, Java, etc.).

## Getting Started

```bash
npm install
npm run dev
```

Runs on [http://localhost:5173](http://localhost:5173).
