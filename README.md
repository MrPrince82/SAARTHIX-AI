## 🧠 What is SAARTHIX AI?

**SAARTHIX AI** is an AI-powered career preparation and placement-readiness platform designed for students, developers and technology professionals.

It brings multiple career tools together in a single platform:

> 🎙️ Practice interviews → 📄 Improve your resume → 🎯 Match jobs → 🗺️ Follow a roadmap → 🤖 Learn with AI

The platform adapts its guidance according to the user's **target technology role** and **experience level**.
